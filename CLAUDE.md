# CLAUDE.md — Weekly Football

Постоянный контекст проекта. Читай этот файл в начале каждой сессии. Полное ТЗ лежит в `docs/TZ.md`.

## Что это

Веб-приложение (PWA) для нашей еженедельной игры в футбол: 15–20 человек, обычно суббота 19:00, общение в WhatsApp.

Идея: игроки заранее отмечаются «Иду», все записавшиеся попадают в список игры, организатор делит их на команды (название, цвет), опоздавших докидывает в готовые команды, матч идёт с таймером и live-счётом, статистика копится сама.

**Главная боль, которую решаем:** не тратить время на деление на команды и ожидание опоздавших.

## Роли

- **Организатор** — создаёт группу и игры, делит на команды, ведёт матч.
- **Игрок** — отмечается, смотрит составы, live и статистику.
- **Гость** — смотрит публичную страницу игры.

Деньги и взносы **не** входят в проект. Не добавлять.

## Стек

- Next.js (App Router) + TypeScript, деплой на Vercel
- Tailwind CSS + shadcn/ui, dnd-kit (для команд)
- Supabase: PostgreSQL, Auth, Realtime, RLS
- Vercel Cron Jobs для автоматизации
- WhatsApp: только ссылки `wa.me` и Open Graph превью (без платного API)

Используй актуальные стабильные версии и сверяйся с официальной документацией, а не с памятью.

## Правила работы

1. **Одна фаза за раз.** Фазы описаны ниже и в `docs/TZ.md`. Не начинай следующую, пока в текущей не выполнены все пункты «Готово, когда». Не добавляй функции из других фаз.
2. **Схема БД только через миграции** в `supabase/migrations/`. Никаких ручных правок через панель Supabase.
3. **Безопасность на уровне базы:** RLS включён на каждой таблице. Права организатора проверяются в политиках, а не только в интерфейсе.
4. **Секреты** только в `.env.local` и в переменных Vercel. Никогда не коммить ключи. `SUPABASE_SERVICE_ROLE_KEY` используется только на сервере.
5. **Mobile-first.** 95% пользователей с телефона. Проверять на ширине 375 px, крупные кнопки (минимум 44 px).
6. **Язык интерфейса — русский.** Код, имена переменных и коммиты — английский.
7. **Маленькие коммиты** после каждого блока задач, понятные сообщения (`feat:`, `fix:`, `chore:`).
8. Если задача требует действий вне кода (создать проект в Supabase, включить провайдер входа, задать переменные в Vercel), **не выдумывай результат**: остановись и дай пошаговую инструкцию для человека.
9. Если требование в ТЗ неясно или противоречиво, задай один короткий вопрос, а не угадывай.

## Заметки по ходу работы

_Сюда записывай решения, которые влияют на следующие фазы._

### Фаза 1
- **Next.js 16**: `middleware.ts` переименован в `src/proxy.ts` (функция `proxy`). Логика обновления сессии — в `src/lib/supabase/middleware.ts`. Перед работой с Next читать `node_modules/next/dist/docs/` (см. @AGENTS.md).
- `npm run typecheck` = `next typegen && tsc --noEmit` — глобальные `PageProps`/`LayoutProps` генерируются Next.
- shadcn использует стиль `base-nova` (Base UI, не Radix) и пакет `cn`. Размеры `Button`/`Input` в `src/components/ui` подняты до 44 px (h-11) — не откатывать при обновлении компонентов.
- Тёмная тема только по системной настройке: `dark:` = `@media (prefers-color-scheme: dark)`, класса `.dark` нет.
- Авторизация: сервер проверяет пользователя через `supabase.auth.getClaims()` (не `getSession`). Анонимная сессия создаётся в server action при первом `create_group`/`join_group`.
- Google: `linkIdentity` для анонимных (требует **Manual linking** в Supabase), `signInWithOAuth` для нового устройства. Колбэк — `/auth/callback`.
- «Текущая группа» = последняя, в которую вступил пользователь (`getAppContext` в `src/lib/session.ts`). Переключателя групп нет — добавить, если понадобится несколько групп.
- БД: `insert/delete` в `players`, `groups`, `group_members` с клиента запрещены грантами; всё создание — через `create_group`/`join_group` (security definer). `update` разрешён по колонкам: `players(name, avatar_url, position)`, `groups(name)`, `group_members(role)`. `level` и `rating` игрок сам менять не может — их будут менять организатор (Фаза 3) и статистика (Фаза 5).
- RLS-хелперы лежат в схеме `private` (не видна через API): `is_group_member`, `is_group_organizer`, `shares_group_with`. Использовать их в политиках следующих фаз.
- Триггер не даёт оставить группу без организатора (ошибка `last_organizer`).
- Код приглашения — 8 символов без 0/O/1/I, регистр при вводе не важен.
- `database.types.ts` написан вручную — после изменения схемы перегенерировать `npx supabase gen types typescript`.
